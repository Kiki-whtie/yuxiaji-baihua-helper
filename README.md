# 玉匣记白话查询 Skill

基于白话版《玉匣记》扫描件OCR整理的古籍检索Skill，可在SkillHub兼容的AI助手中快速查询书中记载的传统民俗条目，仅作文本检索与传统文化参考。

## ✨ 功能特性

- 内置完整白话版《玉匣记》OCR整理文本（分卷存储）
- 自然语言查询：直接问「嫁娶宜忌」「出行吉日民俗记载」即可匹配原文
- 严格古籍还原：仅摘录原文，不编造、不演绎
- 合规安全：内置反迷信声明，不提供算命、改运类服务

## 🚀 一键安装（SkillHub）

在已安装SkillHub CLI的环境中执行：

```bash
skillhub install @Kiki-whtie/yuxiaji-baihua-helper
```

## 🛠️ 手动安装

1. Clone本仓库到本地：

```bash
git clone https://github.com/Kiki-whtie/yuxiaji-baihua-helper.git
```

1. 将整个文件夹放入你的Skill技能目录即可。

## 💡 使用示例

```
> 使用 yuxiaji-baihua-helper，查询玉匣记里关于动土修造的民俗记载
```

输出会返回对应原文段落、出处，并附带民俗参考提示。
